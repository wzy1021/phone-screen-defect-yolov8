## 二、怎么打开

- Word 文档：用 Word 打开后，目录处右键 →“更新域”→ “更新整个目录”，页码和条目会生成。
  文档已经在设置里打开“打开时更新域”，多数情况下 Word 会主动提示。
- PPT：用 PowerPoint 打开，16:9；每页备注里有讲稿，演示者视图可以直接看。
- 字体：正文宋体、标题黑体、代码 Consolas；PPT 用微软雅黑。Windows 自带，不需要额外安装。

## 三、这一阶段做了什么

1. **补测试**：把第 11–14 周散落在终端里的测试整理成一份完整报告，补了接口、性能、
   模型、兼容性、异常和安全检查；发现 13 个问题，修了 10 个（1 个 S1、4 个 S2、5 个 S3），
   留 3 个 S4 建议项。
2. **写手册**：按“装—登—传—看—查—统—管—备”的顺序写操作步骤，配 9 张真实截图，
   把常见报错和处理办法列成表。
3. **整合报告**：把前 14 周的需求、设计、实现、测试串成一份课程设计报告，补了背景、
   国内外现状、方案对比、局限和改进方向。
4. **做答辩材料**：22 页 PPT，按“问题—做法—结果—反思”组织，主动讲清楚合成数据的
   域差异和真实样本不足，不夸大指标。

## 五、几个必须说明的点

1. **指标口径**：0.9932 是 v1 在原测试集上的 mAP50；0.9875 / 0.8883 是混合模型分别在
   原测试集和困难测试集上的 mAP50；0.9593 是混合模型在混合测试集（原+困难）上的 mAP50。
   三组数对应不同测试集，不能混着比。
2. **合成数据**：训练图是程序生成的，和真实照片有域差异。报告和 PPT 都明确写了这一点，
   没有把 0.99 说成真实产线精度。
3. **真实图只有一张**：720×552 碎屏图，误检从 26 个框降到 3 个，只能做案例分析，
   不能算真实 mAP。
4. **遗留问题**：CSRF、登录限流、SQLite 并发没有做，只适合本机演示；这些在测试报告
   第 10 章和课程设计报告 6.3 节都列为局限。
5. **页数**：Word 文档没有写死页数，取决于本机字体和 Word 版本；打开后更新目录即可
   看到实际页码。

## 六、怎么重新生成

在项目根目录执行（用装了 python-docx / python-pptx / matplotlib 的环境）：

```powershell
python week15-18/docs/make_figures.py        # 统计图
python week15-18/docs/make_test_report.py    # 测试报告
python week15-18/docs/make_user_manual.py    # 用户手册
python week15-18/docs/make_course_report.py  # 课程设计报告
python week15-18/docs/make_pptx.py           # 答辩 PPT
python week15-18/docs/qa_check.py            # 结构自检
```

文档里的指标、测试输出、数据库记录数都从 `week11-14/` 下的实际文件读取，
不是手写死的；改了模型或测试结果，重新跑脚本即可同步。
