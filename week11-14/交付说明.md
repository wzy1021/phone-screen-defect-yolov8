## 二、怎么运行

```powershell
cd week11-14
python run.py
# 浏览器打开 http://127.0.0.1:5000
```

也可以双击 `启动系统.bat`（已配置本机 conda 环境 `diffusion-course`）。

演示账号：

- `admin / 123456`：管理员，可看全部记录、修改默认阈值
- `user / 123456`：普通用户，只能看自己的记录

## 三、演示顺序（约 3 分钟）

1. 登录页：说明两种角色，用 admin 登录；
2. 检测页：拖入一张测试图（`datasets/images/test/` 里任意一张），点开始检测；
3. 结果页：看框、类别、置信度，演示下载结果图和导出 CSV；
4. 检测页：一次选 3 张，演示批量检测；
5. 历史页：按日期筛选、翻页、删除；
6. 统计页：4 个卡片 + 柱状图 + 饼图 + 趋势图；
7. 退出，用 user 登录，说明权限差异。

## 四、两点说明

1. **数据是程序化合成的**。课程设计期间收集不到上千张带标注的真实缺陷照片，
   所以写了 `datasets/gen_dataset.py`，随机生成桌面、手机外壳、玻璃反光和六类
   缺陷，标注框由绘制位置直接换算。优点是标签准确、类别可控、可复现；缺点是
   和真实照片有域差异。文档 2.7 节写了真实照片的接入和微调方案。
2. **mAP 只代表合成测试集**。0.9932（v1）/0.9875（mix）的 mAP50 不能当作真实
   产线精度，答辩时要主动说明这一点，不能夸大。
3. **真实图目前只验证了一张**。碎屏图的误检从 26 个框降到 3 个，主裂纹能框出，
   但只有一张图，不能代表所有场景；真实精度要等补标注数据后再评估。改进过程、
   原因分析和 CPU 训练参数见文档第 7 章。
